InvManager information security policy

Last updated: 13 October 2026

This policy covers InvManager (TikTok Shop app name: warehouseShop), a private tool used only by one small UK shop, and every system that stores or handles its data. The business owner owns this policy and reviews it at least once a year and after any incident or major change. Everyone given access must read and follow it.

Network protection

  • The server is reachable only through Cloudflare Tunnel, which connects outbound. No web ports are open on it.
  • Cloudflare Access sits in front of the web app: people sign in with an approved email and a one-time code; machines use a named Cloudflare service token.
  • The server firewall allows only SSH, and root login is disabled.
  • The app checks the signed Cloudflare Access token on every request and records who made each change.
  • TikTok Shop webhook and authorisation addresses reject any request whose TikTok signature does not verify.
  • Cloudflare's DDoS and threat filtering apply to all traffic to the server.

Endpoint protection

  • Company PCs run Microsoft Defender Antivirus with real-time protection and automatic updates.
  • Windows Firewall stays on, and PCs that hold order data use BitLocker disk encryption.

Daily security baseline

  • Multi-factor authentication on TikTok Shop, Cloudflare, DigitalOcean, Google and GitHub accounts.
  • Passwords of at least 12 characters, unique per service, kept in a password manager.
  • Screens lock after 5 minutes idle. Clear desk: no passwords, order printouts or customer details left out.
  • Company devices are not shared with people outside the business.

Access control

  • Least privilege: only the owner has admin access to the server and app credentials. Staff get the inventory app only.
  • No shared accounts. Access is reviewed every 3 months and removed the day it is no longer needed.
  • App secrets and tokens are kept only in owner-only files on the server, never in code, chat or spreadsheets, and are rotated at once if they may have been exposed.

Data classification and encryption

  • Confidential: buyer names, addresses, phone numbers, order details, credentials. Internal: stock, auction logs. Public: product listings.
  • All data is encrypted in transit (TLS/HTTPS). Confidential data is kept only on the UK server and encrypted company PCs, and only the order fields needed for fulfilment are fetched.

Vulnerability management

  • Server security updates install automatically; all packages are updated at least monthly.
  • Windows Update is on for all PCs; the app's dependencies are reviewed monthly.
  • Security notices from Cloudflare, DigitalOcean, TikTok Shop and GitHub are monitored.
  • Critical issues are fixed within 7 days, others within 30 days.

Incident response

The business owner is the incident lead. Anyone who notices a lost device, a strange login or a data leak tells the owner at once. We then contain it (revoke credentials and access), assess what was affected, notify, recover from a clean backup, and write up what changes.

  • TikTok Shop: notified within 24 hours of confirming an incident affecting TikTok Shop data.
  • The UK ICO: within 72 hours when the law requires it.
  • Affected people: without undue delay when they are at high risk.
